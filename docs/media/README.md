# Media

Drop demo assets here with these names so the root README picks them up:

- `board.jpg`  — a photo of the Arty A7-100T running the parser
- `demo.gif`   — the SW0 flip toggling the verdict LED (convert the phone clip:
  `ffmpeg -i clip.mov -vf "fps=12,scale=640:-1" demo.gif`)

Keep each under a few MB. Larger raw videos belong in a GitHub Release, not git.
